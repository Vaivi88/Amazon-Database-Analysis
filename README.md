# Amazon-Database-Analysis
An interactive Excel dashboard for ABC Electronics analyzing 102K+ sales. Tracks $10.1M sales &amp; $4.03M profit, with region-wise, category-wise &amp; yearly trend analysis.
# About 
This is an interactive sales performance dashboard for ABC Electronics. The project analyzes 102,791 orders to track total sales of $10.1M and profit of $4.03M, with deep-dive insights into region-wise performance, product category contribution, and year-over-year sales trends.
# Tools
SQL - For data extraction, cleaning, and transformation.
Power BI - For data modeling, DAX measures, and building an interactive dashboard with slicers.
